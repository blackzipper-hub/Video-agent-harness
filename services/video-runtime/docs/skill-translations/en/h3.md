# H3

`api.provider.generate`, `model: minimax-h3` (or `h3`). Images + reference audio.

## Calling

- `images`: required. References to send into the model for this shot. If using the previous shot's image, treat it as a reference, not an opening-frame lock. `depends_on` only schedules.
- `audios`: this segment's 2-15s reference audio. Audio alone is not allowed.
- `duration`: 4-15 **integer seconds**.
- `resolution`: `768p` or `2k` (do not use 1080p).
- `aspect_ratio`: `9:16` for portrait; defaults to `16:9` if omitted.

## Never

- Pass audio without images.
- Omit still-available references needed for this shot from `images`.
