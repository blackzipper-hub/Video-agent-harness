# Agent Note: 修复媒体任务引用

Status: implemented

[English](2026-09-14-repair-media-selectors.md) | 中文

## 问题

上游任务失败后克隆待执行的下游任务时，可能更新了调度依赖，却让媒体参数仍指向失败任务。下游任务因此可以启动，但无法找到所需输出。

## 决策

修复在所有下游任务克隆完成后，将完整替换映射应用于明确的任务引用字段。单值及有序列表引用与计划提交检查共享定义。提交检查拒绝不可用任务 id，并从引用补齐调度依赖。历史计划及非引用参数保持不变。

## 考虑过的替代方案

**替换所有匹配字符串。** 不采用，因为提示词、URL 和产物 id 不是任务引用。

**要求模型修复全部下游参数。** 不采用，因为 Runtime 负责自动克隆下游任务，必须自行保持可执行输入引用正确。

## 影响

测试用旧参数复现查找失败，并将修复后的参数送入真实媒体插件，仅模拟媒体服务调用。覆盖引用类型、顺序、传递下游、历史不变及计划持久化前拒绝。已失败的 Build 需要显式修复；本次修改不会重新提交付费生成任务，也不解决模型提供方余额不足。
